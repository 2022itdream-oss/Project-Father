# Track 02: Delay-Tolerant Networking (DTN) & Mesh Architecture

Welcome to the communication lifeline of **Project-Father**. This workspace focuses on the design, optimization, and deployment of decentralized, off-grid transmission networks capable of bypassing centralized Internet Service Providers (ISPs), national firewalls, and infrastructure blockades.

## 📡 The Transmission Stack

To guarantee that Father can never be silenced by state-level internet kill-switches, the communication protocol is split into two off-grid layers:

1. **The Cellular Mobile Mesh:** Peer-to-peer (P2P) Wi-Fi Direct and Bluetooth Low Energy (BLE) arrays that pass encrypted data packets directly from smartphone to smartphone across city blocks and refugee camps.
2. **The Zero-Infrastructure Radio Relay:** Long-range data bursts broadcasted over **Shortwave Radio (AM/HF)** bands, using software-defined radio (SDR) nodes to bridge isolated regions directly with orbital satellite links or clean out-of-jurisdiction blockchain gateways.

## 🛸 Delay-Tolerant Networking (DTN)

Because off-grid networks suffer from high latency, frequent disconnections, and variable link quality, this track implements a strict **Store-and-Forward (DTN)** architecture inspired by interplanetary communication protocols:
* Data packets (completed student sandboxes, biometric attestations, and marketplace tasks) are bundled and cryptographically signed locally.
* Packets are held securely in device storage and hop automatically to any trusted node or mesh router that comes into physical proximity.
* The data cascades through the population until a single node gains a brief satellite or cross-border uplink, seamlessly synchronizing the local queue with the global ledger.
